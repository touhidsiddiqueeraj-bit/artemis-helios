# Helios-Artemis

A photovoltaic (PV) system research project implementing a dual-microcontroller predictive Maximum Power Point Tracking (MPPT) controller for solar energy optimization.

## Overview

This project presents the Helios-Artemis system, which partitions the MPPT problem into two planes:
- **Helios (ESP32-S3):** LSTM irradiance forecasting, local retraining, SD logging
- **Artemis (STM32F103):** real-time VS-P&O MPPT, 50 kHz PWM generation, battery management

Validated by a field logger deployed in Sylhet, Bangladesh, with the full study written up as an IJPEDS revision (manuscript `25195-52952-1-SM-REVISED`).

## Figures

Generated by `Code/Python/gen_figures_hires.py`:

1. **fig1_architecture** - System architecture (dual-MCU: Helios + Artemis)
2. **fig2_irradiance** - Sylhet Markov-chain + OU irradiance model
3. **fig3_iv_curves** - PV I–V / P–V characteristics
4. **fig4_lstm** - LSTM predictor performance (R², MAE, residuals, α sensitivity)
5. **fig5_simulation** - Full-day Simulink simulation (6 panels)
6. **fig6_comparison** - Controller efficiency comparison + Monte Carlo
7. **fig7_po_convergence** - VS-P&O convergence analysis
8. **fig8_cost** - BOM breakdown and cost comparison (manuscript Fig. 10)
9. **fig9_validation** - Field-logger ramp-rate validation

Plus `graphical_abstract.py` for the graphical abstract. The manuscript embeds these as 11 figures (including the GitHub-repo QR code).
